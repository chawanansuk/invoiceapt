# ระบบจัดการหอพัก — อพาร์ทเม้นท์ มั่งมีทวีสุข

เว็บแอปจัดการห้องเช่า ผู้เช่า และ (ในเฟสถัดไป) ใบแจ้งหนี้/การชำระเงิน
ต่อยอดจากไฟล์ Excel เดิม (`../room_data.json` คือข้อมูลตั้งต้น 90 ห้อง)

## เทคโนโลยี
- Next.js 16 (App Router) + React 19 + TypeScript
- Prisma 6 + SQLite (dev) / PostgreSQL (prod)
- Tailwind CSS 4
- เซสชันแบบ JWT cookie (jose) + รหัสผ่าน bcrypt

## เริ่มใช้งาน (dev)
```bash
cp .env.example .env          # ตั้งค่า DATABASE_URL และ SESSION_SECRET
npm install
npx prisma migrate dev        # สร้างฐานข้อมูล
npm run seed                  # นำเข้าข้อมูล 90 ห้องจาก ../room_data.json
npm run dev                   # เปิด http://localhost:3000
```
ผู้ใช้เริ่มต้น: **admin / admin1234** (เปลี่ยนรหัสผ่านก่อนใช้งานจริง)

## ฟีเจอร์ปัจจุบัน
### เฟส 1 — จัดการห้อง/ผู้เช่า
- เข้าสู่ระบบ / ออกจากระบบ (ป้องกันทุกหน้าใน `proxy.ts`)
- ภาพรวม: จำนวนห้อง, ห้องว่าง, รายได้ค่าเช่า/เดือน, สถานะตามชั้น
- ห้องพัก: รายการ + กรองตามชั้น/สถานะ, แก้ค่าเช่า/อัตราค่าน้ำไฟ/บัญชีรับเงิน
- ผู้เช่า: ค้นหา, แก้ข้อมูล, เพิ่มผู้เช่าเข้าห้อง, ย้ายออก, ประวัติการเช่า

### เฟส 2 — ออกบิล/รับชำระ
- ออกบิลรายเดือน: เลือกเดือน, กรอกมิเตอร์ไฟ/น้ำทั้งตึกในตารางเดียว
  (ดึงเลขมิเตอร์เดือนก่อนมาเป็น "เลขเก่า" อัตโนมัติ), เห็นยอดรวมคำนวณสดๆ ระหว่างพิมพ์
- คำนวณค่าไฟ/น้ำตามหน่วยที่ใช้ + ค่าน้ำขั้นต่ำ + ค่าเช่า/ส่วนกลาง/ขยะ/อื่นๆ
- ออกใบแจ้งหนี้ทีละห้องหรือทั้งตึก, รายการบิล + กรองตามเดือน/สถานะ + ยอดค้างรวม
- หน้าพิมพ์ใบแจ้งหนี้ (พิมพ์/บันทึก PDF จากเบราว์เซอร์) พร้อม **QR PromptPay** ระบุยอด
- บันทึกการชำระ: อัปโหลดสลิป (บีบอัดรูปฝั่ง client), ยืนยัน/ยกเลิกการรับเงิน,
  ชำระบางส่วนได้, สถานะบิลอัปเดตอัตโนมัติ (ค้าง/บางส่วน/ชำระแล้ว)

### เฟส 3 (เริ่มแล้ว) — OCR อ่านสลิป/มิเตอร์ด้วย AI
- **อ่านสลิปอัตโนมัติ**: ถ่ายรูป/อัปโหลดสลิปในหน้าใบแจ้งหนี้ → AI ดึงยอดเงิน,
  วันที่โอน, ผู้โอน, เลขอ้างอิง มากรอกให้อัตโนมัติ (ตรวจสอบก่อนบันทึก)
- **อ่านมิเตอร์อัตโนมัติ**: ปุ่มกล้อง 📷 ข้างช่องเลขมิเตอร์ไฟ/น้ำในหน้าออกบิล →
  ถ่ายรูปหน้าปัด → AI อ่านเลขมาใส่ให้
- ใช้ Claude vision (Anthropic API) — ต้องตั้ง `ANTHROPIC_API_KEY`
  (ไม่ตั้งก็ยังกรอกมือได้ปกติ ปุ่ม AI จะแจ้งว่ายังไม่ได้ตั้งค่าคีย์)

## โครงสร้างฐานข้อมูล
`User`, `Room`, `Tenant`, `Lease`, `MeterReading`, `Invoice`, `InvoiceLine`,
`Payment`, `BankAccount`, `BillingProfile` (โหมดเบิกได้/เลขผู้เสียภาษี)

## ตั้งค่า OCR (Claude vision)
คัดลอก `.env.example` เป็น `.env` แล้วใส่คีย์จาก https://console.anthropic.com/ :
```
ANTHROPIC_API_KEY="sk-ant-..."
# ตั้งรุ่นเองได้ (ค่าเริ่มต้น claude-opus-4-8); ถ้าเน้นถูก/เร็ว ลอง claude-haiku-4-5
# ANTHROPIC_OCR_MODEL="claude-opus-4-8"
```

## เฟสถัดไป
- ส่งบิล + QR เข้า **LINE** ผู้เช่าอัตโนมัติ, พอร์ทัลผู้เช่า,
  รายงานภาษี / ใบเสร็จแบบมีเลขผู้เสียภาษี (BillingProfile โหมด tax)

## Deploy
ตั้ง `provider = "postgresql"` ใน `prisma/schema.prisma`, ตั้ง `DATABASE_URL`
ไปยัง PostgreSQL (เช่น Neon/Supabase) แล้ว deploy บน Vercel
(`npx prisma migrate deploy` ตอน build)
